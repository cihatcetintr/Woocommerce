# Save Search Eklentisi 

Bu eklenti, kullanıcıların php tabanlı online alışveri süreçleri içerisinde sayfa arama linklerini kaydetmelerini, kaydelilen aramalara dair yeni ürünler eklendiğinde e-posta bildirimleri almalarını sağlar.

## Özellikler

- 🔐 Kaydedilen Ürünler Sekmesi
  - Kaydedilen linklerin listesi
  - Kayıt isim güncelleme
  - Kayıt silme
  - Veritabanında anlık olarak güncelleme

- 👤 E-Posta Bildirimleri
  - Kaydedilen ürün linkinin 24 saatte bir güncelleme yapılarak yeni ürünler eklenmişse e-posta bildirimi sağlar.

## Teknolojiler

- Frontend:
  - Html-Css
  - Javascript
  - Php
  - Mysql
